FUNCIONALIDADES IMPLEMENTADAS:
------------------------------

DIContainer:
- InjectionToken<T> — Token tipado com phantom field para type-safety estrita
- register<T>(token, factory) — Registros transientes (nova instância cada resolve)
- registerSingleton<T>(token, factory) — Singletons (instância compartilhada)
- registerInstance<T>(token, instance) — Instância pré-existente
- resolve<T>(token) / tryResolve<T>(token) — Resolução de dependências
- createChild() — Containers filhos com herança
- has(), delete(), clear() — Gerenciamento de registry
- createToken<T>(name) — Helper conveniente

EngineEvents:
- EngineEventMap — Mapa abrangente com 50+ eventos tipados em 13 categorias:
  * Engine Lifecycle (init, start, stop, dispose)
  * World Lifecycle (created, disposed, reset)
  * Physics (stepped, collision start/end)
  * Render (frame, invalidate, pre/post)
  * Module System (registered, started, stopped, error, disposed)
  * Input (pointer, keyboard, gamepad, focus)
  * Scripting (trigger, variable-changed, rule-changed, package-changed)
  * Objects/Entities (added, removed, renamed, changed, selection)
  * Camera (changed, target-changed, first-person)
  * Terrain/Environment (changed, environment-changed)
  * Assets (loaded, unloaded, error)
  * Editor (tool-changed, workspace-changed, project-changed, history)
  * Debug (log, metric)
- EngineEventBus interface — Contrato type-safe para event bus
- createEngineEventBus() — Factory retornando EventBus<EngineEventMap>
- EngineEvents constants — Todos nomes de eventos como const strings (prevenção de typos)

Subsystem:
- SubsystemContext — Contexto passado na inicialização (container, events, runtime check, invalidate)
- Subsystem interface — Métodos obrigatórios: initialize, start, stop, dispose, update opcional
- SubsystemWithAPI<TApi> — Interface estendida para exposição de API pública
- SubsystemStatus — Enum de status (uninitialized → disposed/error)
- SubsystemState — Estrutura de informação de estado
- createSubsystemToken(name) — Cria InjectionToken<Subsystem> tipado
- KnownSubsystems — Identificadores conhecidos (PHYSICS, RENDER, INPUT, SCRIPTING, AUDIO, NETWORK, ASSETS, UI)
- isSubsystem() / isSubsystemWithAPI() — Runtime type guards
